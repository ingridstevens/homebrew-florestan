# Homebrew tap for Florestan.exe

[Florestan.exe](https://github.com/ingridstevens/florestan) is a Mac menu bar app: paste a YouTube or YouTube Music
link, and the song or playlist lands in your Apple Music library.

```sh
brew install --cask ingridstevens/florestan/florestan
```

Update with `brew upgrade --cask florestan`, remove with `brew uninstall --cask florestan`.

Florestan.exe isn't notarized by Apple, so the first time you open it macOS blocks it: click **Done**, then go to
**System Settings › Privacy & Security** and click **Open Anyway**. Only download content you own or have the
rights to.
